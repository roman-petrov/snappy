# 🚇 Transit pass comparison

## 👀 Overview

Pick a monthly pass before the first commute week. Values stay short so cells stream cleanly while the advice stays
useful.

## 📊 Matrix

| Pass       |   Cap   | Cost | Note                 |
| :--------- | :-----: | ---: | -------------------- |
| City       | **low** |   45 | `bus` + metro        |
| Metro only |  _mid_  |   38 | no buses             |
| Regional   |  high   |   72 | **weekend** zones    |
| Day stack  |  edge   |   12 | pipe \| check        |
| Legacy     | ~~old~~ |   30 | keep until `renewal` |

## 📖 Reading the columns

**Cap** is the monthly spend ceiling. _Cost_ is the sticker price before discounts. Use `renewal` day as the switch
point, and retire ~~legacy~~ passes when the new one activates.

## ✅ Close

Choose **one** pass for the trial month, then revisit with _real_ ride counts.
